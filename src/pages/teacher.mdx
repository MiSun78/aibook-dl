### 보내 주신 템플릿을 고친 부분

실습 1 노트북에는 수행평가 템플릿(SDGs14 펭귄)의 탐색 부분을 교과서 실습 1 순서에 맞춰 정리해 넣었습니다. 템플릿 전체에서 고칠 점은 아래와 같고, 분류(실습 3)·회귀(실습 2)·군집(실습 4) 부분은 Ⅱ-02를 만들 때 고친 노트북으로 넣겠습니다.

| 템플릿 | 고칠 점 | 고친 방법 |
|---|---|---|
| 펭귄(분류) | 혼동 행렬의 행·열 이름을 `pd.unique()`(데이터에 나온 순서)로 붙임. `confusion_matrix`는 이름의 알파벳순으로 행렬을 만들어 순서가 다르면 이름이 엇갈림 | `labels=model.classes_`로 같은 순서를 씀 |
| 펭귄(분류) | 3단계 목록에 '정규화하기'가 있지만 실제로는 하지 않음. k-NN은 거리로 판단하므로 체질량(수천 g)이 날개 길이(수백 mm)를 압도함 | 훈련 데이터로 `fit`한 스케일러로 정규화한 뒤 k-NN 학습 |
| 펭귄(분류) | '가장 구별력이 좋은 특성 2개(지느러미 길이, 체질량)' — 이 둘은 젠투만 잘 가르고 아델리와 턱끈은 거의 겹침 | 산점도로 확인되는 부리 길이 + 날개 길이(또는 부리 깊이) 조합을 근거와 함께 고르게 함 |
| 펭귄(분류) | 가장 좋은 k를 테스트 데이터 정확도로 고름. 테스트 데이터가 모델 선택에 쓰여 성능이 부풀려짐 | 훈련 데이터 안에서 교차 검증으로 k를 고르고, 테스트 데이터는 마지막에 한 번만 평가 |
| 펭귄(분류) | 모델 활용 설명의 '체질량지수' | 체질량(몸무게, g). 체질량지수(BMI)는 다른 개념 |
| 펭귄(분류) | 혼동 행렬 주석 `fmt='0.2f'`와 실제 코드 `fmt='d'`가 다름, '데이터프레이셋' 등 오타 | 바로잡음 |
| 신체(회귀) | 1단계에 '분류 문제'라고 적혀 있음 | 회귀 문제 |
| 신체(회귀) | 다중 선형 회귀의 회귀식이 목둘레 계수 하나만 출력함(계수 3개 중 2개 빠짐) | 모든 독립변수의 계수를 출력 |
| 신체(회귀) | 히스토그램 설명의 `hue='종속변수'` — 허리둘레는 연속값이라 색 구분에 쓰기 어려움 | 회귀에서는 hue 없이 그리거나 산점도로 관계를 봄 |
| 신체(회귀) | 이상치 함수의 주석 '그룹별'·`show_details` 인수가 쓰이지 않음 | 정리 |
| 군집(실습 4) | 큰 오류 없음. 결론 표의 실루엣 점수는 데이터·라이브러리 버전에 따라 조금 달라질 수 있음 | 표의 값을 '예시'로 표시하고, 학생 결과를 직접 적게 함 |

**사이트 안 기록 칸.** 정리하기 아래 '나의 기록'에 적은 내용은 학생 기기의 브라우저에만 저장됩니다. 학생이 [기록 복사하기]를 눌러 구글 클래스룸이나 패들렛에 붙여 넣게 하거나, 구글 폼을 만들어 사이트 설정 파일(src/config.ts)의 `recordFormUrl`에 주소를 넣으면 [구글 폼에 제출하기] 버튼이 나타납니다.
