# 선생님용 운영 안내

이 디지털 교과서는 교과서 Ⅱ-03 '인공 신경망과 딥러닝'(126~161쪽)과 같은 순서로 되어 있습니다. 각 절 제목 옆에 교과서 쪽수가, 교과서의 활동·실습·더 알아보기에는 같은 번호가 붙어 있어 종이 교과서와 나란히 펴 놓고 수업할 수 있습니다. 교과서에 없는 보조 활동은 '교과서 밖 활동'으로 표시했습니다.

## 남은 차시에 맞춘 운영 예시

지도서는 이 중단원을 13차시(20~32차시)로 계획합니다. 남은 차시가 적은 반은 아래처럼 묶어 운영할 수 있습니다.

| 소단원 (교과서 쪽수) | 지도서 | 6차시 반 | 4차시 반 |
|---|---|---|---|
| 03-1 인공 신경망의 이해 (126~132) | 20~21차시 | 1차시: 퍼셉트론부터 활동 8까지 | 1차시: 활동 8은 시연으로 |
| 03-2 신경망 모델 설계와 구현 과정 (133~142) | 22~24차시 | 2차시: 구현 과정과 식품 분류 예제<br />3차시: 실습 5, 더 알아보기 | 2차시: 식품 예제는 코드 읽기로, 실습 5 실행 |
| 03-3 컴퓨터 비전 (143~154) | 25~28차시 | 4차시: 컴퓨터 비전, 활동 9~11<br />5차시: 실습 6 | 3차시: 활동 10·11 중심, 실습 6은 시연 |
| 03-4 음성 인식과 자연어 처리 (155~161) | 29~32차시 | 6차시: 활동 12·13, BERT와 GPT | 4차시: 같은 내용을 압축 |

## 교과서와 다르게 한 부분

| 교과서 | 이 디지털 교과서 | 이유 |
|---|---|---|
| 127쪽 퍼셉트론 설명 | 가중치를 직접 움직이는 퍼셉트론 조종기를 덧붙임 | 128쪽 '퍼셉트론의 한계(비선형 문제)'를 직접 확인하게 하려고 |
| 129쪽 활동 7 (텐서플로 플레이그라운드) | 같은 실험을 할 수 있는 은닉층 실험실을 덧붙임 | 학교망에서 외부 사이트가 막힐 때를 대비해서 |
| 137~140쪽 실습 5 코드 | 같은 순서의 코드를 접어 두고, 노드 수와 학습 횟수는 선택 상자로 바꾸게 함 | 코드를 직접 짜기 어려운 학생도 실행하고 결과를 해석할 수 있게 |
| 141쪽 더 알아보기 (사진 촬영 후 코랩) | 화면에 숫자를 그리면 바로 분류하는 그리기 판 | 촬영, 업로드 없이 몇 분 안에 끝낼 수 있게 |
| 134~137쪽 식품 분류 예제 | 같은 내용을 코드와 함께 설명 | 예제 코랩 노트북은 교과서 데이터(food_nn.csv)를 받으면 추가 예정 |

## 학생 기록 모으기

단원 끝의 정리하기에 적은 내용은 학생 기기의 브라우저에만 저장됩니다. 학생이 [기록 복사하기]를 눌러 구글 클래스룸이나 패들렛에 붙여 넣게 하거나, 구글 폼을 만들어 사이트 설정 파일(src/config.ts)의 `recordFormUrl`에 주소를 넣으면 [구글 폼에 제출하기] 버튼이 나타납니다.
