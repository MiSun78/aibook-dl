<div>

지도학습에서 수치를 예측하는 **선형 회귀**는 정답이 있는 데이터로 연속적인 값을 예측한다. 집값, 기온, 판매량, 키, 몸무게처럼 연속적인 수치를 예측하는 문제에 쓴다. 선형 회귀 모델을 만들면 독립 변수와 종속 변수 사이의 선형(직선) 관계를 찾아 값을 예측할 수 있다.

- **독립 변수**: 예측에 쓰는 입력값. 예) 목둘레
- **종속 변수**: 예측해서 구하려는 결괏값. 예) 허리둘레

독립 변수가 1개이면 **단순 선형 회귀**, 2개 이상이면 **다중 선형 회귀**라고 한다.

</div>
<FigRegLines />
</Split>

선형 회귀 모델은 다음 식으로 나타낸다.

**종속 변수(y) = 절편(b) + 회귀계수(a₁) × 독립 변수(x₁) + 회귀계수(a₂) × 독립 변수(x₂) + …**

- **회귀계수**: 독립 변수가 1만큼 변할 때 종속 변수가 평균적으로 변하는 양. 절댓값이 클수록 종속 변수에 주는 영향이 크다(단, 독립 변수들의 단위와 범위가 비슷할 때).
- **절편**: 독립 변수가 모두 0일 때 종속 변수의 예측값

최적의 선형 회귀 모델을 만든다는 것은 독립 변수로 종속 변수를 가장 잘 예측하는 회귀계수와 절편을 찾는 것이다.

선형 회귀로 풀 수 있는 문제: 기온과 강수량에 따른 배춧값, 연도에 따른 해수면 높이, 공부 시간에 따른 성적, GDP에 따른 행복 점수, 광고비에 따른 판매량 등

</Sec>

<Sec id="s2" title="선형 회귀 성능 평가" pages="97~98쪽">

모델이 실제로 관찰된 값을 얼마나 정확하게 예측하는지 확인하려면 성능을 평가해야 한다. 실제 관찰한 값을 **실젯값**, 모델이 예측한 값을 **예측값**이라고 한다. 선형 회귀의 성능은 **오차 함수**와 **결정계수**로 평가한다.

### (1) 오차 함수

기계학습 모델의 목표는 실젯값과 차이가 가장 작은 예측값을 찾는 것이다. 실젯값과 예측값의 차이를 **오차**라고 하고, 오차를 구하는 함수를 **오차 함수**(손실 함수, 비용 함수)라고 한다. 오차 함수의 값이 작을수록 모델의 성능이 좋다.

| 오차 함수 | 구하는 방법 |
|---|---|
| MAE (평균절대오차) | 오차의 절댓값을 평균한 값 |
| MSE (평균제곱오차) | 오차를 제곱해 평균한 값 |
| RMSE (평균제곱근오차) | MSE의 제곱근. 원래 단위(cm 등)로 돌아와 해석하기 쉽다. |

### (2) 결정계수(R²)

<Split>
<div>

**결정계수**(R²; R squared)는 모델이 데이터를 얼마나 잘 설명하는지 나타내는 값이다. 0~1 사이 값이고, 1에 가까울수록 모델이 데이터를 잘 설명한다. 예를 들어 목둘레로 허리둘레를 예측하는 모델의 결정계수가 0.681이면, 허리둘레 변화의 약 68.1%를 목둘레로 설명할 수 있다는 뜻이다.

| 결정계수 | 설명력 |
|---|---|
| 0 | 예측력이 없음 |
| 0 초과 0.3 미만 | 약함 |
| 0.3 이상 0.5 미만 | 중간 정도 |
| 0.5 이상 0.7 미만 | 높음 |
| 0.7 이상 1 이하 | 매우 강함 |

X = df['neck'].values.reshape(-1, 1)   # 독립 변수: 2차원 배열(열 1개)로 바꾼다
y = df['waist'].values                 # 종속 변수
