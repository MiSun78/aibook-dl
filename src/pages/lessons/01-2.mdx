<Sec id="s1" title="데이터의 개념과 유형" pages="67~68쪽">

문제 해결에 필요한 데이터를 모으려면 어떤 데이터가 필요한지, 어떻게 모을지 분명하게 계획하고, 정확하고 믿을 수 있는 데이터를 확보해야 한다.

<Split>
<div>

**데이터**는 숫자, 문자, 이미지 등을 관찰하거나 측정해 모은 사실이나 값이고, **데이터 속성**은 데이터를 이루는 구체적인 정보 요소이다.

데이터 속성은 숫자로 표현하는 **수치형 데이터**와, 정해진 여러 범주 중 하나의 값을 가지는 **범주형 데이터**로 나뉜다. 수치형 데이터는 다시 둘로 나뉜다.

- **연속형 데이터**: 시간처럼 두 값 사이에 또 다른 값이 있을 수 있는 데이터
- **이산형 데이터**: 우리 반 인원수처럼 두 값 사이에 다른 값이 없는 데이터
- **범주형 데이터**: 남/여, 만족/불만족, 상/중/하, 혈액형처럼 정해진 값 중 하나를 고르는 데이터

예를 들어 학생 건강 체력 평가(PAPS) 데이터에서 성별은 범주형, 팔 굽혀 펴기 횟수는 이산형, 유연성(cm)은 연속형 데이터이다.

</div>

데이터는 형식에 따라 둘로 나눌 수도 있다.

- **정형 데이터**: 속성이 미리 정해져 있고, 행과 열로 이루어진 표 형태인 데이터. 예) 꽃받침 길이와 너비, 꽃잎 길이와 너비, 품종의 5개 속성으로 된 붓꽃(Iris) 데이터
- **비정형 데이터**: 이미지, 영상, 텍스트, 소리처럼 형식과 구조가 복잡해 속성을 미리 정하기 어려운 데이터. 예) 같은 붓꽃이라도 사진으로 모으면 비정형 데이터이다.

</Sec>

<Sec id="s2" title="데이터 수집 방법" pages="69쪽">

기계학습은 많은 데이터를 학습해 성능 좋은 모델을 만드는 것이 목표이므로 양질의 데이터를 모으는 것이 중요하다.

1. **공공 데이터 수집하기**: 통계청, 국토교통부, 환경부 등 공공 기관이 제공하는 데이터를 쓴다. 통계청의 국가통계포털(kosis.kr), 공공데이터포털(data.go.kr), 기상자료개방포털(data.kma.go.kr), 환경통계포털 등이 있다.
2. **민간 데이터 수집하기**: 캐글(kaggle.com), UCI 기계학습 저장소, AI 허브(aihub.or.kr), 구글 데이터셋 검색 등에서 인공지능 모델용 데이터를 구한다.
3. **직접 수집하기**: 공개된 데이터가 없으면 센서, 설문, 관찰로 직접 모은다. 스마트폰이나 스마트워치의 센서로 실시간 데이터를 모을 수도 있다.

</Ask>

<Sec id="s3" title="문제 해결에 적합한 데이터 선정" pages="70~71쪽">

기계학습으로 문제를 해결하려면 먼저 문제를 분명하게 정의하고, 필요한 데이터를 충분히 골라야 한다.

1. **문제의 유형 분석**: 해결할 문제를 분석해 알맞은 기계학습 유형(분류, 예측, 군집, 인식, 자연어 처리, 생성)을 정한다.
2. **데이터의 유형 탐색**: 문제 해결에 필요한 데이터(정형, 비정형)를 정한다.
3. **데이터 수집 방법 선택**: 직접 모으거나 제공되는 데이터를 내려받는다.

데이터는 모델에 큰 영향을 주므로 모을 때 편향성과 공정성, 개인 정보 노출, 저작권 등을 함께 따져야 한다.

<Split>
<div>

### 데이터 편향성과 공정성

**데이터 편향**은 데이터를 모으거나 분석할 때 생기는 오류나 왜곡이다. 데이터의 불균형이나 편향은 공정성 문제로 이어져, 특정한 속성을 가진 사람들이 부당하게 불이익을 받을 수 있다.

- 자동차 충돌 실험에 성인 남성 체형의 인체 모형만 쓰면 여성에게 알맞지 않은 안전 기준이 만들어질 수 있다.
- 운동화 사진만으로 학습한 모델은 샌들이나 부츠를 신발로 알아보지 못할 수 있다.

</div>
