그림을 그리면 오른쪽에 작은 흑백 그림이 나타난다. 신경망이 실제로 받는 그림이다. 가로 28칸, 세로 28칸, 모두 784칸이고, 칸마다 밝기를 나타내는 수가 하나씩 들어 있다. [숫자로 보기]를 켜면 그 수를 볼 수 있다.

신경망 학습에 쓰는 **MNIST** 데이터셋은 미국의 고등학생과 공공기관 직원이 쓴 손글씨 숫자 70,000장을 모은 것이다. 60,000장은 학습에, 10,000장은 평가에 쓴다. 원래 픽셀값은 0(검정)부터 255(흰색)까지인데, 255로 나누어 0~1 사이로 바꾼 뒤 신경망에 넣는다. 앞에서 배운 **정규화**다.

[자동 가운데 맞춤]은 그린 글씨를 적당한 크기로 줄여 가운데에 놓는 처리다. MNIST의 숫자들도 모두 이렇게 가운데에 맞춰져 있다. 이 처리가 왜 필요한지는 5번 활동에서 확인한다.

<Step no={3} kind="개념" title="숫자 인식 신경망의 설계도">

<NetDiagram />

- **입력층 784개**: 픽셀 하나가 입력 하나다. 입력층의 크기는 데이터의 특징 개수로 정해진다.
- **은닉층 128개, 64개**: 크기는 우리가 정한다. 은닉층은 픽셀 무늬를 조합해 "위쪽에 가로줄이 있다" 같은 특징을 스스로 만든다. 활성화 함수로는 ReLU를 쓴다. ReLU는 음수는 0으로, 양수는 그대로 내보낸다.
- **출력층 10개**: 0부터 9까지 숫자마다 하나씩이다. **softmax** 함수가 출력을 모두 더해 1이 되는 확률로 바꾼다. 확률이 가장 큰 숫자가 신경망의 답이다. 그리기 판 오른쪽의 막대가 바로 이 10개의 확률이다.

코랩에서는 케라스(Keras)라는 도구로 이 신경망을 만든다. 코드가 길어 보여도 뼈대는 아래 네 줄이다. 2단원에서 배운 기계학습 모델 구현 과정과 같다.

```python
model = keras.Sequential([...])           # 1. 설계: 층을 쌓는다
model.compile(loss=..., optimizer='adam') # 2. 환경 설정: 틀린 정도를 재는 방법과 고치는 방법을 정한다
model.fit(X_train, y_train, epochs=5)     # 3. 학습: 훈련 데이터로 가중치를 고친다
model.evaluate(X_test, y_test)            # 4. 평가: 처음 보는 테스트 데이터로 성능을 잰다
```

**손실 함수**는 예측이 정답과 얼마나 다른지 재는 자이고, **최적화 함수**는 그 차이를 줄이는 방향으로 가중치를 고치는 방법이다. **에포크(epoch)**는 훈련 데이터 전체를 한 번 다 보는 것을 말한다. 5에포크는 6만 장을 다섯 번 반복해서 본다는 뜻이다.

<Step no={6} kind="개념" title="성능은 무엇으로 판단할까?">

코랩 실습에서는 정확도가 두 번 나왔다.

- **훈련 정확도**: 신경망이 학습에 쓴 데이터를 얼마나 맞히는지
- **테스트 정확도**: 학습 중에 한 번도 보지 않은 데이터를 얼마나 맞히는지

모델의 실력은 테스트 정확도로 판단한다. 시험 문제를 미리 보고 외운 학생의 점수가 실력을 보여 주지 못하는 것과 같다. 학습을 너무 오래 시키면 훈련 정확도는 100%에 가까워지는데 테스트 정확도는 오르지 않거나 오히려 떨어지기도 한다. 훈련 데이터를 외워 버린 이 상태를 **과적합**이라고 한다.
