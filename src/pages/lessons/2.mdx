신경망 모델도 2단원에서 배운 기계학습 모델과 같은 순서로 만든다. 다른 점은 3단계에서 신경망을 직접 설계한다는 것이다.

1. **문제 정의하기**: 해결하려는 문제와 목표, 쓸 수 있는 데이터, 기대하는 결과를 분명히 한다.
2. **데이터 수집 및 전처리하기**: 문제에 맞는 데이터를 모은다. 이미지 인식 문제라면 이미지를, 자연어 처리 문제라면 텍스트를 모은다. 그다음 결측치, 이상치를 처리하고 정규화한다.
3. **모델 생성하기**
    1. 신경망 모델 설계하기: 입력층, 은닉층, 출력층을 구성하고 각 층의 노드 개수와 활성화 함수를 정한다.
    2. 신경망 모델 환경 설정하기: 손실 함수와 최적화 함수를 정한다.
    3. 신경망 모델 학습하기: 훈련 데이터로 학습시킨다.
4. **모델 평가 및 예측하기**: 테스트 데이터로 성능을 측정하고, 개선할 방향을 찾는다.

<Sec id="ex" title="신경망 모델 생성하기: 식품 분류 신경망" pages="134~136쪽" kind="예제">

식품의 **당도**(sweet)와 **아삭함**(crunchy) 값으로 과일, 단백질, 채소를 분류하는 신경망을 만든다. 세 종류는 직선 하나로 나뉘지 않으므로 비선형 분류 모델이 필요하다.

- 특징(X): sweet, crunchy
- 타깃(y): class (0 과일, 1 단백질, 2 채소)
- 데이터: food_nn.csv (교과서 134쪽 안내 링크)

<DataFiles files={['food_nn.csv']} />

### 1) 신경망 모델 설계하기

<NetDiagram
  layers={[
    { label: '입력층', size: 2, inputs: ['당도', '아삭함'] },
    { label: '은닉층 1', size: 32, note: 'ReLU' },
    { label: '은닉층 2', size: 16, note: 'ReLU' },
    { label: '출력층', size: 3, note: 'softmax' },
  ]}
  outputs={['과일(0)', '단백질(1)', '채소(2)']}
  hot={0}
  caption="입력층 노드 수는 특징의 개수(2개), 출력층 노드 수는 분류할 클래스 수(3개)와 같다. 은닉층 노드 수(32개, 16개)는 데이터의 크기와 복잡성에 따라 정한다."
/>

- **ReLU**: 입력이 음수면 0, 양수면 그대로 내보내는 활성화 함수로, 은닉층에서 주로 쓴다.
- **softmax**: 출력값을 0~1 사이의 확률로 바꾸고 합이 1이 되게 하는 함수로, 출력층에서 주로 쓴다.

케라스(keras)에서는 층을 차례로 쌓는 `Sequential`과, 이전 층의 모든 노드와 연결되는 층인 `Dense`로 설계한다. 입력층을 뺀 모든 층에 활성화 함수가 필요하다.

```python
from keras.models import Sequential
from keras.layers import Dense

model = Sequential()
model.add(Dense(32, input_dim=2, activation='relu'))   # 입력층(2) → 은닉층(32)
model.add(Dense(16, activation='relu'))                # 은닉층(16)
model.add(Dense(3, activation='softmax'))              # 출력층(3)
```

### 2) 신경망 모델 환경 설정하기

학습시키기 전에 두 가지를 정한다.

- **손실 함수**: 예측값과 실제 정답의 차이를 재는 함수. 정답이 0, 1, 2 같은 정수인 분류 문제에서는 `sparse_categorical_crossentropy`를 쓴다.
- **최적화 함수**: 손실 함수의 값을 줄이는 방향으로 가중치를 고치는 함수. 딥러닝에서 가장 많이 쓰는 `adam`을 쓴다.

```python
model.compile(loss='sparse_categorical_crossentropy',   # 손실 함수
              optimizer='adam',                         # 최적화 함수
              metrics=['accuracy'])                     # 평가 지표: 정확도
```

### 3) 신경망 모델 학습하기

<Split>
<div>

처음에는 가중치가 무작위로 정해져 있어서 엉뚱한 예측을 한다. 입력이 신경망을 통과해 예측값을 내는 과정을 **순전파**, 예측값과 정답의 차이(손실)를 이용해 거꾸로 가중치를 고치는 과정을 **역전파**라고 한다. 이 과정을 여러 번 반복하면서 신경망은 데이터의 패턴을 학습한다. 반복 횟수는 `epochs`로 정한다.

</div>
<FigTrain />
</Split>

```python
model.fit(X, y, epochs=500)   # 데이터로 500번 반복 학습
```

학습이 진행될수록 손실(loss)은 줄고 정확도(accuracy)는 높아진다.

</Sec>

<Sec id="s3" title="신경망 모델 평가 및 예측하기" pages="137쪽">

학습시킨 모델은 `evaluate`로 성능을 평가하고, `predict`로 새 데이터를 예측한다.

```python
model.evaluate(X, y)   # 손실과 정확도를 출력
model.predict(X)       # 클래스마다의 확률을 출력
```

`predict`의 결과는 클래스마다의 확률이다. 예를 들어 어떤 식품에 대해 [0.98, 0.00, 0.01]이 나왔다면 0번 클래스(과일)일 확률이 가장 크므로 과일로 예측한다.
