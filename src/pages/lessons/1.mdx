<Sec id="s2" title="인공 신경망과 퍼셉트론" pages="127쪽">

<Split>
<div>

사람의 뇌는 수많은 **뉴런**(신경 세포)으로 이루어져 있고, 뉴런들은 **시냅스**로 연결되어 신호를 주고받는다. **인공 신경망**은 이 뉴런과 시냅스가 작동하는 원리를 흉내 낸 모델이다.

</div>
<FigNeuron />
</Split>

<Split>
<div>

**퍼셉트론**은 인공 신경망을 이루는 가장 기본 단위로, 여러 신호를 입력받아 하나의 신호를 출력한다.

1. 입력값(x₁, x₂, …)에 각각의 **가중치**(w₁, w₂, …)를 곱한다. 가중치는 그 입력이 얼마나 중요한지를 나타낸다.
2. 곱한 값들을 모두 더한다(가중합). 여기에 **편향**(b)을 더하면 출력이 1이 되는 기준을 옮길 수 있다.
3. 가중합이 **활성화 함수**를 거친다. 임곗값을 넘으면 1, 넘지 못하면 0을 출력한다.

</div>

### 직접 해 보기: 퍼셉트론 조종하기 <small>(교과서 밖 활동)</small>

가중치와 편향을 바꾸면 퍼셉트론이 어떻게 판단하는지 확인해 보자. 교과서에 나온 AND 게이트를 먼저 만들어 본다.

<Perceptron />

<Ask label="해 보기">

1. AND(두 입력이 모두 1일 때만 1)를 만들어 보자.
2. OR(하나라도 1이면 1)를 만들어 보자.
3. XOR(두 입력이 서로 다를 때만 1)도 만들 수 있을까?

</Ask>

그림의 검은 선이 퍼셉트론이 데이터를 나누는 기준이다. 퍼셉트론 하나는 **직선 하나**로만 나눌 수 있기 때문에, 직선으로 나뉘는 **선형 문제**만 해결할 수 있다.

</Sec>

<Sec id="s3" title="다층 신경망, 심층 신경망, 딥러닝" pages="128쪽">

<Split>
<div>

XOR처럼 직선 하나로 나눌 수 없는 문제를 **비선형 문제**라고 한다. 퍼셉트론 하나로는 풀 수 없다.

**다층 신경망**(MLP)은 입력층과 출력층 사이에 **은닉층**을 넣어 여러 퍼셉트론이 함께 작동하게 한 구조다. 이렇게 하면 비선형 분류가 가능해진다.

</div>
<FigXor />
</Split>

<Split>
<div>

- **입력층**: 데이터를 입력받는 층
- **은닉층**: 들어온 값에 가중치를 곱해 계산하고, 활성화 함수로 비선형적으로 바꿔 다음 층으로 전달하는 층
- **출력층**: 신경망의 최종 예측값을 내는 층

**심층 신경망**(DNN)은 은닉층이 여러 개인 신경망으로, 더 복잡한 비선형 문제를 해결할 수 있다. 은닉층이 많을수록 신경망이 '깊다'고 한다.

**딥러닝**은 심층 신경망으로 입력 데이터의 복잡한 패턴을 학습해 문제를 해결하는 분야다. 이미지 인식, 음성 인식, 자연어 처리처럼 기존 기계학습으로 풀기 어려웠던 문제에서 성능을 크게 높였다.

</div>

<Sec id="a7" title="신경망 모델에서 은닉층과 노드의 역할 알아보기" pages="129쪽" kind="활동 7">

텐서플로 플레이그라운드에서 은닉층이 어떤 역할을 하는지 확인한다.

<p><a class="btn" href="https://playground.tensorflow.org/" target="_blank" rel="noopener">텐서플로 플레이그라운드 열기</a></p>

1. 활성화 함수(Activation)는 **ReLU**, 문제 유형(Problem type)은 **Classification**을 선택한다.
2. 데이터(DATA)에서 **Exclusive or**(XOR)를 선택한다. 주황과 파랑은 데이터가 속한 두 클래스다.
3. 은닉층(HIDDEN LAYERS) 수를 **0**으로 두고 ▶ 버튼을 누른다. 학습 횟수(Epoch)가 늘어나도 분류가 잘 되지 않는 것을 확인한다.
4. 은닉층 수와 은닉층 안의 노드 수를 늘리고 다시 ▶ 버튼을 누른다. 학습이 진행될수록 비선형 분류가 잘 되는지 확인한다.

연결선 위에 마우스를 올리면 가중치를 볼 수 있다. 파란색은 양수, 주황색은 음수이고, 가중치의 절댓값이 클수록 선이 두껍다.

<Ask label="하나 더 해 보기">

- 다른 데이터를 선택해 신경망 분류 모델을 만들어 보자.
- 은닉층 없이 분류할 수 있는 데이터는 무엇인지 찾아보자.
- 비선형 분류가 필요한 데이터에서 은닉층 수와 노드 수를 늘려 보자.

</Ask>

<Sec id="s5" title="딥러닝 활용 분야" pages="130~131쪽">

딥러닝은 컴퓨터 비전, 자연어 처리, 음성 인식, 생성 등 여러 분야에서 쓰인다.

| 분야 | 하는 일 | 활용 예 |
|---|---|---|
| 컴퓨터 비전 | 이미지와 영상에서 객체를 식별하고 특성을 파악한다 | 얼굴 인식으로 잠금 해제, 자율주행 자동차의 객체 분할, 의료 영상에서 질병 탐지 |
| 자연어 처리 | 사람이 쓰는 언어(자연어)를 이해하고 처리한다 | 인공지능 비서, 기계 번역, 인공지능 챗봇 |
| 음성 인식 | 음성을 텍스트로 바꾸어 자연어 처리 기술로 이해하고 처리한다 | 인공지능 스피커, 자동차 내비게이션, 음성 보안 접근 |
| 생성 | 텍스트, 이미지, 음성, 영상 같은 콘텐츠를 만들거나 바꾼다 | 이미지 생성, 동영상 생성, 텍스트 생성 |

</Sec>
