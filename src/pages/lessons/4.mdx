<Sec id="s1" title="음성 인식과 자연어 처리 이해" pages="155쪽">

<Split>
<div>

우리는 대부분 말로 다른 사람과 소통한다. 인공지능은 어떻게 사람의 말을 알아듣고 그에 맞는 일을 할까?

**음성 인식**은 사람의 목소리에서 나오는 음성 신호를 컴퓨터가 해석해 텍스트로 바꾸는 기술이다. **자연어**(natural language)는 사람이 일상생활에서 쓰는 언어이고, **자연어 처리**(NLP; Natural Language Processing)는 사람이 쓰는 언어의 의미를 분석해 컴퓨터가 처리할 수 있게 만드는 작업이다.

자연어 처리는 음성 인식으로 만든 텍스트를 바탕으로 다음 과정을 거친다.

1. **데이터 전처리**: 불필요한 문자를 지우거나 형식을 통일한다.
2. **형태소 분석**: 문장을 의미가 있는 가장 작은 단위인 형태소로 나눈다.
3. **문장 구조 파악**: 문장 안에서 단어나 구의 관계를 파악한다.
4. **의미 분석**: 문장이나 단어의 의미를 파악한다.

</div>
<FigSpeaker />
</Split>

인공지능 스피커는 정해진 범위 안에서 음성 인식과 자연어 처리를 한다. 마이크로 들어온 음성을 텍스트로 바꾸고, 자연어 처리로 뜻을 파악한 뒤 미리 약속된 동작을 한다.

<Sec id="s2" title="딥러닝을 활용한 음성 인식" pages="156쪽">

<Split>
<div>

초기의 음성 인식은 입력된 음성의 파형이 어떤 음에 가까운지, 어떤 단어를 나타내는지 알아보는 방식이었다. 딥러닝이 이미지 인식의 성능을 크게 높인 것처럼 음성 인식의 성능도 크게 높였다.

음성 인식은 음성 데이터를 처리하고 **음향 모델**과 **언어 모델**을 이용해 단계적으로 음성을 텍스트로 바꾸는데, 이 과정에서 딥러닝을 쓴다.

- **끝점 검출**: 음성의 시작과 끝을 자동으로 찾는다.
- **전처리**: 잡음 등을 없앤다.
- **음향 모델**: 어떤 소리가 어떤 음에 해당하는지 확률로 판단한다.
- **언어 모델**: 어떤 단어 다음에 어떤 단어가 나올 확률을 계산한다.
- **후처리**: 숫자, 영어, 문장 부호를 되살린다.

최근에는 단계를 나누지 않고 하나의 모델이 한꺼번에 음성을 인식하는 **종단 간**(End-to-End) 방식을 많이 쓴다.

</div>

</Split>

<Sec id="more" title="생성형 인공지능이란 무엇일까?" pages="157쪽" kind="더 알아보기">

- **생성형 인공지능**: 기존 데이터에서 패턴을 학습해 텍스트, 이미지, 음악 같은 새로운 콘텐츠를 만들어 내는 인공지능 기술이다.
- **기반 모델**(foundation model): 대규모 데이터로 미리 학습해 둔 대형 인공지능 모델이다. 추가 학습을 하면 텍스트 생성, 번역, 이미지 생성 등 여러 작업에 쓸 수 있다.
- **대규모 언어 모델**(LLM): 대량의 텍스트로 훈련해 사람의 다양한 자연어를 해석하고 생성할 수 있는 인공지능이다.
- **챗봇 서비스**: 챗GPT처럼 대규모 언어 모델을 이용해 자연어 대화로 콘텐츠를 만들어 주는 서비스이다.

</Sec>

<Sec id="s3" title="딥러닝을 활용한 자연어 처리" pages="158~159쪽">

텍스트를 처리할 때도 딥러닝은 성능을 크게 높인다. 텍스트를 분석해 정보를 뽑아내려면 **자연어 이해 모델**이, 자연스러운 텍스트를 만들려면 **자연어 생성 모델**이 필요하다.

<Split>
<div>

### 자연어 이해 모델

자연어 이해 모델은 대량의 텍스트를 분석해 자연어의 규칙을 이해한다. 곧 문장에 담긴 문법과 의미를 이해한다.

예를 들어 "나는 과일 중에서 배를 좋아한다."와 "나는 항구에서 배를 보았다."의 '배'는 뜻이 다르다. 단어의 뜻을 알려면 앞뒤의 단어를 모두 봐야 한다.

대표적인 예는 구글이 2018년에 소개한 **BERT**이다. BERT는 문장 중간에 빈칸을 만들고, 그 자리에 어떤 단어가 알맞은지 **앞뒤 단어를 모두 참고해** 예측하며 훈련한다. 이렇게 단어 사이의 관계를 파악해 자연어의 의미를 이해한다.

### 자연어 생성 모델

자연어 생성 모델도 대량의 텍스트를 미리 학습하지만, 주어진 문장 다음에 가장 알맞은 단어나 문장을 예측해 **새 문장을 만든다**는 점이 다르다. 검색창의 자동 완성, 기계 번역, 챗봇, 소설 쓰기 등에 쓰인다.

대표적인 예는 OpenAI가 개발한 **GPT**(Generative Pre-trained Transformer)이다. GPT는 **앞 단어들의 정보로 다음 단어를 예측**하도록 훈련한다.

</div>
<FigBertGpt />
</Split>

두 가지 훈련 방식을 아주 작은 언어 모델로 직접 해 보자.

<NextWord />

GPT는 버전이 올라갈수록 매개 변수(가중치) 수가 크게 늘었다. GPT-1(2018년)은 약 1억 1,700만 개, GPT-2(2019년)는 약 15억 개, GPT-3(2020년)는 약 1,750억 개이다. 매개 변수가 많을수록 더 많은 것을 학습하고 새로운 것을 예측하는 능력이 좋아진다.

<Ask>

'다음 단어 예측'에서 [확률대로 끝까지 쓰기]를 여러 번 눌러 보자. 학습한 문장에 없던 새 문장이 만들어지는가? 이상한 문장이 나온다면 그 이유는 무엇일까?

</Ask>

<Sec id="s4" title="음성 인식과 자연어 처리 사례" pages="160쪽">

| 사례 | 하는 일 |
|---|---|
| 인공지능 스피커 | 사람의 말을 알아듣고 노래 추천, 날씨 안내 같은 알맞은 반응을 한다. 음성 인식과 함께 말뜻을 이해하는 능력이 필요하다. |
| 영상 자막 생성 | 영상 속 음성을 인식해 자막을 만들고, 다른 언어로 번역해 보여 주기도 한다. |
| 기계 번역 | 한 언어를 다른 언어로 번역한다. 자연어 처리 초기부터 연구가 많이 이루어졌다. |
| 감정 분석 | 글에 담긴 감정이 긍정, 부정, 중립 중 무엇인지 파악한다. 예) 상품 후기, SNS 분석 |
| 검색 엔진 | 검색 문장을 이해해 알맞은 결과를 보여 주고, 다음에 입력할 말을 추천한다. |
| 텍스트 생성 | 주어진 조건이나 정보로 사람이 쓴 것 같은 자연스러운 글을 만든다. |

음성 인식과 자연어 처리 시장은 스마트 기기의 보급, 인공지능 기술의 발전, 데이터 증가에 힘입어 빠르게 커지고 있다.

</Sec>
