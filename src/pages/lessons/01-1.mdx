사람은 새로운 개념을 배울 때 여러 예시와 경험에서 패턴을 찾고, 그것으로 새로운 문제를 해결한다. **기계학습**(ML; Machine Learning)도 개념에 맞는 예시 데이터에서 숨은 패턴을 찾고, 그것을 바탕으로 새로운 데이터를 예측하고 판단한다. 기계학습은 인공지능의 한 분야이고, 인공 신경망과 딥러닝은 기계학습의 한 방법이다.

### 왜 기계학습을 쓸까?

**전통적인 프로그래밍**은 입력값을 사람이 정한 분명한(명시적인) 규칙으로 처리해 출력한다. 학생 100명의 영어·수학 점수로 평균을 내는 프로그램은 규칙이 분명하므로 이 방법으로 충분하다.

하지만 모든 문제를 규칙으로 적을 수 있는 것은 아니다. 수많은 동물 사진을 보고 종을 맞히는 규칙, 얼굴 사진으로 감정을 알아내는 규칙, 대화에 알맞은 답을 고르는 규칙은 사람이 분명하게 적기 어렵다. 이런 지능적인 문제를 풀기 위해 기계학습이 등장했다.

<Sec id="s2" title="데이터로 학습하기" pages="62쪽">

사람이 다양한 경험으로 어떤 개념을 '학습'하듯이, 기계학습도 다양한 데이터나 경험이 담긴 데이터를 학습해 스스로 **모델**을 만든다.

- **사람**: 어릴 때부터 개와 고양이를 많이 보며 학습했기 때문에, 머릿속에 둘을 구분하는 모델이 이미 만들어져 있다.
- **기계학습**: 개와 고양이 사진 데이터를 충분히 학습해, 둘을 구분하는 분류 모델을 만든다.

기계학습 모델을 만들려면 문제에 맞는 데이터가 필요하다.

| 기계학습 문제 | 필요한 데이터 |
|---|---|
| 전력 사용량 예측 | 날씨 데이터, 전력 사용량, 건물 정보 |
| 음성 감정 인식 | 음성 데이터, 감정 종류 |
| 기계 고장 진단 | 기계 소리, 고장 여부 |
| 도로 교통량 예측 | 날짜, 시간, 도로 구간 정보, 차량 평균 속도 |
| 스팸 메일 분류 | 메일 텍스트, 스팸/정상 여부 |

</Sec>

<Sec id="more" title="컴퓨터는 사람이 쓴 손 글씨를 어떻게 인식할 수 있을까?" pages="63쪽" kind="더 알아보기">

손 글씨 숫자는 사람이나 나라마다 모양이 조금씩 다르고, 방향이나 크기, 두께가 달라지면 알아보기 더 어렵다. 이런 경우를 모두 규칙으로 적는 것은 거의 불가능하다.

하지만 다양한 손 글씨 숫자 데이터를 많이 모아 기계학습을 하면, 숫자마다의 특징과 패턴을 스스로 찾아 분류하는 모델을 만들 수 있다. ① 손 글씨 숫자 데이터셋으로 **학습**해 분류 모델을 만들고, ② 새로운 손 글씨를 넣어 **예측**한다.

좋은 성능의 모델을 만들려면 많은 양의 데이터를 모아야 하고, 데이터가 한쪽으로 치우치지 않도록 알맞은 형태로 가공하고 전처리해야 한다.

</Sec>

<Sec id="s3" title="기계학습으로 해결할 수 있는 문제" pages="64~65쪽">

<Split>
<div>

기계학습은 사람이 분명한 규칙으로 찾기 어려운 문제를, 사람의 경험이 담긴 데이터로 모델을 만들어 해결한다. 기계학습으로 해결하는 문제의 유형은 다음과 같다.

- **분류**: 데이터를 미리 정한 여러 그룹 중 하나로 나눈다. 예) 스팸 메일 분류
- **예측**: 미래의 값이나 알려지지 않은 값을 추정한다. 예) 주택 가격 예측
- **군집**: 비슷한 특성의 데이터를 같은 그룹으로 묶는다. 예) 비슷한 성향의 고객 묶기
- **인식**: 이미지, 음성, 텍스트를 알아보고 이해한다. 예) 표정으로 감정 알기
- **자연어 처리**: 사람의 언어를 이해하고 처리한다. 예) 자동 번역
- **생성**: 새로운 데이터나 콘텐츠를 만든다. 예) 그림, 글, 음성 생성

</div>
<FigProblemTypes />
</Split>

기계학습은 추천 시스템, 이미지 인식, 기계 번역, 의료 영상 진단, 금융 예측, 농업과 기후 변화 대응(드론·위성 사진으로 작물 상태 살피기) 등 여러 분야에서 쓰인다.

<Sec id="a2" title="기계학습으로 해결 가능한 문제 정의하기" pages="66쪽" kind="활동 2">

기계학습으로 해결할 수 있는 문제를 찾아보고, 인공지능 시스템이 그 문제를 어떻게 해결할 수 있는지 그림으로 표현해 보자.

1. 기계학습으로 해결 가능한 문제에 제목을 붙이고 간단한 그림을 그려 보자.
2. 문제를 해결하려면 어떤 데이터를 모아야 하는지 간단히 적어 보자.
3. 인공지능 시스템이 데이터를 활용해 문제를 어떻게 해결하는지 동작 방식을 구체적으로 적어 보자.

<Ask label="예시">

**AI 컵 반납기**: 라벨을 뗀 컵과 라벨이 붙은 컵 사진을 모아 학습시킨다. 반납기에 컵을 넣으면, 라벨이 없는 컵은 '수거 가능', 라벨이 붙은 컵은 '수거 불가'로 인식해 처리한다.

</Ask>
