<Split>
<div>

**분류 모델**은 입력 데이터를 미리 정해 둔 여러 클래스 중 하나로 나누는 모델이다. 새 데이터가 들어오면 어느 클래스에 속하는지 예측한다. 예를 들어 메일 분류 모델은 메일의 내용, 보낸 사람, 들어 있는 링크 등 여러 특징을 보고 스팸인지 아닌지 정한다.

분류 모델을 만들려면 **특징**(feature)과 **타깃**(target)이 필요하다. 타깃은 예측하려는 속성이고, 특징은 타깃을 예측하는 데 쓰는 속성이다.

- **클래스**: 타깃의 범주. 예) 과일, 채소
- **레이블**: 각 데이터의 실제 클래스(정답)

| 당도 | 아삭함 | 식품(타깃) |
|---|---|---|
| 10 | 1 | 과일 |
| 3 | 8 | 채소 |
| 7 | 2 | 과일 |

</div>

분류 모델의 핵심 목표는 클래스 영역을 나누는 **경계**를 찾는 것이다. 경계가 직선(평면)이면 **선형 분류**, 곡선이거나 여러 조각으로 꺾이면 **비선형 분류**라고 한다. 분류 알고리즘에는 결정트리, 로지스틱 회귀, k-최근접 이웃 등이 있다.

분류 문제의 예: 뇌종양인지 정상인지, 도로에 균열이 있는지, 마실 수 있는 물인지, 재활용 쓰레기의 종류

### (1) 결정트리

<Split>
<div>

**결정트리**(decision tree)는 나무를 거꾸로 세운 모양의 알고리즘이다. 맨 위 **루트 노드**에서 출발해 갈림길마다 특징에 대한 질문(분할 기준)으로 데이터를 나눈다.

1. 데이터를 가장 잘 나누는 특징을 고른다.
2. 그 특징의 분할 기준으로 데이터를 둘 이상의 하위 그룹으로 나눈다.
3. 나뉜 하위 그룹에서 다시 기준을 골라 나누기를 되풀이한다.
4. 모든 데이터가 한 클래스로 나뉘거나 정해 둔 종료 조건(예: 최대 깊이)에 이르면 멈춘다. 맨 끝 **단말 노드**에 클래스가 정해진다.

특징값을 기준으로 나누므로 정규화가 필요 없다. 하지만 너무 깊이 나누면 트리가 지나치게 복잡해져 과적합이 생기기 쉽다.

</div>

### (2) 로지스틱 회귀

<Split>
<div>

**로지스틱 회귀**(logistic regression)는 선형 회귀에 **로지스틱 함수**를 적용한 알고리즘이다. 로지스틱 함수는 S자 곡선으로, 어떤 값이든 0~1 사이로 바꾼다. 이 값을 각 클래스에 속할 확률로 보고 분류한다. 예를 들어 점수로 합격 확률을 계산해 0.5 이상이면 합격, 아니면 불합격으로 분류한다.

이름에 '회귀'가 들어 있지만 분류 알고리즘이다. 경계가 직선인 선형 분류 모델이고, 세 개 이상의 클래스도 분류할 수 있다. 학습이 잘되도록 특징을 정규화해서 쓰는 경우가 많다.

### (3) k-최근접 이웃

<Split>
<div>

**k-최근접 이웃**(kNN; k-Nearest Neighbor)은 예측할 데이터와 가장 가까운 k개의 데이터를 보고 예측하는 방법이다. 분류할 때는 가까운 k개 중 가장 많은 클래스로 정한다. k=3이고 가까운 3개가 파란색 2개, 빨간색 1개이면 파란색으로 분류한다.

거리는 주로 **유클리디언 거리**(두 점 사이의 직선 거리)로 잰다. 두 점 (1, 1)과 (5, 4)의 유클리디언 거리는 √((5−1)² + (4−1)²) = 5이고, **맨해튼 거리**(가로, 세로로만 움직인 거리)는 |5−1| + |4−1| = 7이다. 거리로 판단하므로 특징의 범위가 크게 다르면 정규화가 꼭 필요하다.

<Sec id="s3" title="분류 모델 성능 평가" pages="108쪽">

<Split>
<div>

분류 모델의 대표적인 성능 지표는 **정확도**(accuracy)이다. 정확도는 전체 데이터 중 예측값과 실젯값이 같은 데이터의 비율이다.

**혼동 행렬**(confusion matrix)은 실제 클래스와 예측 클래스를 비교해 모델이 각 클래스를 얼마나 맞히고 무엇과 헷갈렸는지 나타낸 표이다. 아래는 펭귄 종 분류 모델의 혼동 행렬 예이다. 대각선 칸이 맞힌 수이다.

| 실제 \ 예측 | 아델리 | 턱끈 | 젠투 |
|---|---|---|---|
| 아델리 | **42** | 2 | 0 |
| 턱끈 | 3 | **18** | 0 |
| 젠투 | 0 | 0 | **36** |

정확도 = (42 + 18 + 36) ÷ 101 ≈ 0.95

</div>
<FigConfusion />
</Split>

두 클래스(예/아니요)를 분류할 때는 혼동 행렬의 칸을 TP, TN, FP, FN이라고 부른다. 정확도 외에 **정밀도**와 **재현율**도 함께 본다(115쪽).

- **정밀도** = TP ÷ (TP + FP): 모델이 '예'라고 한 것 중 실제로 '예'인 비율. 스팸 필터처럼 정상 메일을 스팸으로 잘못 거르는(FP) 일이 큰 문제일 때 중요하다.
- **재현율** = TP ÷ (TP + FN): 실제 '예'인 것 중 모델이 '예'라고 찾아낸 비율. 암 진단처럼 실제 환자를 놓치는(FN) 일이 큰 문제일 때 중요하다.

</Sec>

<Sec id="opt4" title="로지스틱 회귀, 최근접 이웃으로 펭귄 종 분류하기" pages="114~115쪽" kind="선택 활동 4">

실습 3과 같은 데이터로 로지스틱 회귀와 k-최근접 이웃 모델을 만들고 결정트리와 비교해 보자. 실습 3 노트북의 뒤쪽 칸이 이 활동이다.

**정규화하기**: k-최근접 이웃은 거리로 판단하므로 특징의 범위를 맞춰야 한다. 로지스틱 회귀도 정규화하면 학습이 안정된다. 이때 **데이터를 먼저 나눈 뒤 훈련 데이터로만 정규화 기준(최솟값, 최댓값)을 정하고**, 테스트 데이터는 그 기준으로 바꾸기만 한다. 테스트 데이터는 '처음 보는 데이터' 역할을 해야 하기 때문이다.

```python
scaler = MinMaxScaler()
X_train_s = scaler.fit_transform(X_train)   # 훈련 데이터로 기준을 정하고 바꾸기
X_test_s = scaler.transform(X_test)         # 테스트 데이터는 같은 기준으로 바꾸기만
lr = LogisticRegression().fit(X_train_s, y_train)
knn = KNeighborsClassifier(n_neighbors=5).fit(X_train_s, y_train)
```

**혼동 행렬 그리기**: `confusion_matrix(y_test, lr_pred)`로 혼동 행렬을 구하고 `sns.heatmap`으로 그린다. 행은 실젯값, 열은 예측값이고 순서는 Adelie, Chinstrap, Gentoo이다. 교과서의 예시 결과에서 로지스틱 회귀는 아델리와 젠투는 모두 맞혔지만 턱끈펭귄 3마리를 아델리로 잘못 분류했다.
